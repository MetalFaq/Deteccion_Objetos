# Model artifacts

Los pesos no se versionan en Git. Registre para cada modelo:

- URI o ubicacion remota;
- SHA-256;
- arquitectura y version del backend;
- version del dataset;
- metricas de validacion y test;
- licencia;
- fecha y responsable de aprobacion.

Mantenga separados checkpoints de entrenamiento, modelos aprobados y exportaciones de despliegue.
