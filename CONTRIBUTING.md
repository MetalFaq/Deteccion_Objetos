# Contribuir

1. Cree una rama pequena y enfocada.
2. No agregue datos, modelos, secretos ni resultados generados al repositorio.
3. Ejecute `uv lock --check`, `uv run ruff check .` y `uv run pytest`.
4. Documente cambios de contratos, clases, metricas o formatos.
5. Incluya evidencia reproducible para cambios de rendimiento o exactitud.
